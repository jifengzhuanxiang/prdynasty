01产品简报

在写任何镜头之前，先把"卖什么、卖给谁、凭什么"钉死——这是整支片子的地基。

它是什么

深圳大学志愿者联合会宣传部（PR）的 2026 招新落地页。vinext 全栈站点，核心是一个会随光标"流动发光"的镜面高光特效（WebGL specular），气质温暖、编辑感、有人味。

目标观众

对摄影 / 设计 / 新媒体感兴趣的在校新生与低年级同学；刷朋友圈、视频号、小红书时被"真实感 + 一句戳中"留下的那种人。

核心主张

「把你的灵感，做成校园里真正发生的作品。」——灵感不是停在草稿里，而是被发布、被看见、被带走。

独特价值（为什么是 PR）

  • 三个真实方向：摄影 / 平面设计 / 公众号
  • 留下真实作品，不是空泛"部门体验"
  • 在真实任务里练落地、攒协作、认识一起生活的人
  • 门槛友好：不必一开始就很会
⚠️ 数据安全：方案中所有出镜照片均为站点自带公开展示素材（public/assets/*.jpg），二维码为真实招新群码，仅原样使用、不做篡改；片中二维码有效期以页面"8 月 28 日前有效"为准，成片前需复检页面是否更新。

02创意策略 · 大创意

"你的灵感，还停在草稿里吗？" 用一个"流动的光"作为全片线索——光划过哪里，PR 的世界就在哪里亮起来：一张照片显影、一张海报成形、一个故事被发出、一群人出现。光 = 灵感的火花，PR = 让它成真的地方。一句话收束：把灵感，做成真的。

为什么是"光"？因为它就是该产品最有辨识度的视觉签名（specular 高光描边）。片子的视觉语言不从外部另造，而从产品自身生长——这是本方案遵循的方法论核心。

签名动效（贯穿全片）

「镜面流光」——一道沿圆角边缘滑过的高光描边（对应站点 data-specular 特效）。开场用它唤醒品牌，中段用它"点亮"每一张卡片与每一句文案，结尾用它做一次优雅扫光收束。节奏遵循：关键信息落定后必须呼吸（批量动效收尾留 0.5s 静止，品牌字标落定 hold ≥1s）。

04音乐与音效

BGM

温暖、有节拍的 indie-pop / acoustic-pop，约 100–110 BPM，人声留白多、有机感强，匹配"真实、有人味"的调性。快切段（S4）所有切点卡在拍上。

交付两版：带 BGM 版 + 无 BGM 版（保留 SFX），方便后期自配音乐。

SFX 节奏句式

  • riser→impact→sparkle：光起 / 主张落定 / 二维码扫亮
  • light / glass 类：流光划过、卡片点亮
  • paper / data 类：三张卡片"发牌"入场
  • film / crowd 类：真实照片蒙太奇的环境暖音

注：ui/ 类合成反馈音需逐个试听，不整目录放行。

07制作说明与下一步

本方案已按 video-shotcraft 方法论完成"产品检查 → 视觉方向 → 功能镜头映射 → 分镜"。要落地成片，建议走自主自由创作模式：你已给清创意方向，由 Agent 连续推进到渲染，中途不逐镜打断。

素材管线（关键原则）

  • 真实页面元素（三分组卡、加入页、二维码）必须起本地 dev server 真实截图（2x 纹理 + 元素级抠图），不手搓 UI。
  • 手搓仅用于非复刻场景：品牌字标、流光、标题字卡。
  • 截图前冻结：二维码原样、有效期复检。

工程与交付

  • Remotion 工程 + PageCam（2.5D 页面相机）+ ClipCard / Caption 组件。
  • 确定性渲染（固定种子，逐帧可复现），无 Math.random / Date.now。
  • 交付：MP4（带 BGM / 无 BGM 两版）+ 关键静帧 + 可导出剪映工程。
环境提示：当前站点为 vinext/Next 全栈（需 Node ≥22.13，本地已具备），含 WebGL 特效，真实截图需在带 GPU 的本地环境运行 dev server 完成。如你确认要"做出来"，我将按上述模式启动：起服务 → 截图 → 搭 Remotion 工程 → 渲染 → 独立终检。也可先只挑几个想用的镜头卡（见 video-shotcraft 画廊）告诉我。
